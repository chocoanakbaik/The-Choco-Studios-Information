Teknologi dan pendekatan

Teknologi yang dipakai produk TCS. Teknologi Chocobot Guardian dan Privacy Guardian dicantumkan setelah produknya dikonfirmasi.

Choco AI

Aplikasi web berbasis browser dengan HTML, CSS, dan JavaScript. Dihosting di Netlify dengan fungsi serverless, memakai Supabase untuk akun dan basis data, serta layanan model AI melalui Groq.

Sara AI (Help Center)

Situs bantuan statis dengan HTML, CSS, dan JavaScript di Netlify. Pertanyaan ke Sara diteruskan lewat fungsi serverless ke layanan model AI melalui Groq.

KasirKita

Aplikasi desktop Windows berbasis Python dengan antarmuka Tkinter dan database SQLite lokal. Alur kasir inti tidak membutuhkan server atau koneksi internet.

Situs TCS

Situs statis modular dengan HTML, CSS, dan JavaScript tanpa framework.
