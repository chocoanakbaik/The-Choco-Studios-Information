# Rencana Konten The Choco Studios

Dokumen kerja internal untuk melengkapi pusat informasi. Konten publik hanya diperbarui setelah fakta dikonfirmasi. Jangan menampilkan rahasia operasional, kredensial, atau detail proyek yang belum layak diumumkan.

## Sudah dikonfirmasi
- Nama: The Choco Studios (TCS). Studio kreatif multisektor oleh solo developer, bukan perusahaan.
- Mulai 12 Desember 2023 dari proyek Chocobot Guardian. Belum ada tonggak lain.
- Visi, misi, nilai utama, pasar awal, dan strategi bahasa ada di `data/site.js`.
- Nama pendiri ditampilkan; kisah pendiri tidak.
- Prinsip: tidak membolehkan hacking, penyebaran data ilegal, atau tindakan ilegal.
- Produk publik: Choco AI (Sara AI adalah Help Center-nya). Produk lain masih dalam pengembangan/menyusul.
- Sebagian produk berbayar, sebagian gratis. Dua proyek internal dirahasiakan.
- Semua teknologi boleh disebut. Choco AI memakai iklan Adsterra.
- Kontak: email, telepon, dan Google Form (link menyusul). Respons paling lama 3 hari.
- Hak cipta ditampilkan; produk tidak boleh dijual ulang kecuali versi khusus.
- Pasar kedua: Asia. Tombol ganti bahasa menyusul. Catatan rilis: tanggal + perubahan, sumber resmi = pendiri.

## Aturan pembaruan
1. Jawab pertanyaan dalam `questionnaire.md` satu per satu atau per kelompok.
2. Simpan fakta final di file data atau halaman yang sesuai, bukan di satu file HTML besar.
3. Jangan mengubah status produk berdasarkan perkiraan.
4. Verifikasi link, klaim, tanggal, dan kompatibilitas sebelum publikasi.
5. Pertahankan halaman awal ringan; komponen, gaya, data, dan fungsi dipisahkan.
